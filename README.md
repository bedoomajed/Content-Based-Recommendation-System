# 🎬 AI Movie Recommendation System

An AI-powered movie recommendation system built using Python, Pandas, Scikit-learn, and Streamlit.

The system recommends movies based on similarity between genres using Content-Based Filtering and Cosine Similarity.

---

# 🚀 Features

- Movie recommendation based on user input
- Content-Based Recommendation System
- Cosine Similarity algorithm
- Interactive UI using Streamlit
- CSV movie dataset
- Top similar movie suggestions
- Match similarity percentage

---

# 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit

---


---

# 📊 Dataset

The dataset contains:
- 100 movies
- Genres
- Ratings

Example:

| Title | Genre | Rating |
|------|------|------|
| Interstellar | sci-fi drama | 9.0 |
| Inception | sci-fi action thriller | 8.8 |

---

# 🧠 AI Concepts Used

## Content-Based Filtering
The recommendation system suggests movies similar to the selected movie based on genres.

## Cosine Similarity
Used to calculate similarity between movie genre vectors.
